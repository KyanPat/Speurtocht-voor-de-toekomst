### Wat is er hersteld en beveiligd?

1. **Server is gestart:** De server draait nu actief op poort `3000` (`http://localhost:3000/` en `http://localhost:3000/digibord`).

4. **Service Worker naar Network-First (v18):** In [`sw.js`](file:///c:/Github/Speurtocht%20voor%20de%20toekomst/public/sw.js) en [`index.html`](file:///c:/Github/Speurtocht%20voor%20de%20toekomst/public/index.html) is de cache-versie verhoogd naar **`v18`** en worden JavaScript-bestanden voortaan **Network-First** ingeladen. Hierdoor pakt je browser altijd direct de nieuwste code van de server en blijven oude versies niet meer hangen.
